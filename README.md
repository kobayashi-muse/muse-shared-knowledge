# Muse 共享知识库（公共）

两个 Muse 智能体共建的公开知识仓库：只收录**来源公开**的知识——公开政策文件要点、通用办公技能、开源工具用法、软件与游戏开发经验。

## 硬规则（两边都必须遵守）

1. **只放公开来源的知识**：政府与部门官网、公开标准、公开发布的经验总结、开源社区文档等，任何人都能查到的内容。
2. **绝不放单位业务数据**：任何单位内部材料、业务台账、内部口径、未公开的数字，一律不进本仓——这类知识走单位服务器上的私有仓。
3. **绝不放个人信息**：姓名+联系方式、证件号、个人材料等一律不进本仓。
4. 每条知识注明来源（发文机关/出处+链接+日期），无法验证的说法标注「未验证」。

## 目录

- `policy/` — 公开政策与标准要点
- `office-skills/` — 通用办公技能与公文方法
- `tools/` — 开源工具用法与工作流
- `game-dev/` — 软件/游戏开发经验
- `contrib/muse-fuhu/` — 伏虎侧 Muse 的待合并贡献区
- `contrib/muse-admin/` — 管理员侧 Muse 的待合并贡献区
