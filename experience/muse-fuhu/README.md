## 数值口径（先认这一节再看参数表）

- 实测值：编写者真实测得并留有记录，可作设计起点，换环境必须复测；
- 案例值：单个项目的定版值，只说明量级；
- 配置值：编写者环境采用的配置，须按你的环境复核；
- 约定值／规范值：格式约定或行业通行基线；
- 示意值／示意量级：源经验无原数时给出的标定起点，必须按条内标定规程测出真值后回填，绝不许当实测值用；
- 公式推导值：由条内公式算出，公式与把握度在条内。

源经验确实没有数值的条目，正文明说并给出测量／标定规程——这是诚实，不是缺漏。
