# 办文审核增补清单（专题6：办文与公文规范）

- 形成日期：2026-11-26（夜间深学块）
- 定位：增补清单，直接并入办文审核动作逐条勾核；依据均为公开规范，每条标注来源编号（见文末来源清单）。
- 说明：数值为 GB/T 9704—2012《党政机关公文格式》原文规定；个别实务换算（如行距磅值）已注明出处性质，不冒充国标原文。

## 一、版式与版心（依据〔1〕GB/T 9704—2012 第4、5章）

- [ ] 纸张为 A4（210 mm×297 mm），成品尺寸无偏差。
- [ ] 版心尺寸 156 mm×225 mm；天头（上白边）37 mm±1 mm，订口（左白边）28 mm±1 mm（实务页边距：上 3.7 cm、下 3.5 cm、左 2.8 cm、右 2.6 cm〔3〕）。
- [ ] 全文文字颜色为黑色（发文机关标志、红色分隔线、印章除外）。
- [ ] 每面排 22 行、每行 28 字并撑满版心；行距按固定值约 28 磅排版（国标以「每面 22 行」定行距，28 磅为实务折算值〔3〕，汇报材料实务口径为 28–30 磅〔6〕）。

## 二、字体字号与标题（依据〔1〕第5.2.2、7.2、7.3条；〔2〕）

- [ ] 正文及公文格式各要素一般用 3 号仿宋体字，无擅自换字体、改字号。
- [ ] 发文机关标志用小标宋体字、红色，居中排布，上边缘至版心上边缘 35 mm。
- [ ] 标题用 2 号小标宋体字，编排于红色分隔线下空二行，居中；回行词意完整、排列对称，呈梯形或菱形，不出现词组被拆断的回行。
- [ ] 正文每自然段左空二字、回行顶格；公文首页必须显示正文。
- [ ] 结构层次序数严格按「一、」「（一）」「1.」「（1）」四级，不跳级、不混用；第一层黑体、第二层楷体、第三层和第四层仿宋体。
- [ ] 主送机关编排于标题下空一行、左侧顶格，名称后标全角冒号；主送过多致首页无正文时，移至版记标注。
- [ ] 发文字号：年份标全称并用六角括号「〔〕」，发文顺序号不加「第」字、不编虚位（1 不写成 01），数字后加「号」字；上行文发文字号居左空一字。
- [ ] 签发人：「签发人」三字用 3 号仿宋体，签发人姓名用 3 号楷体，居右空一字。
- [ ] 密级、保密期限、紧急程度如需标注，用 3 号黑体顶格编排于版心左上角（份号第一行、密级第二行），保密期限数字用阿拉伯数字。

## 三、落款、印章与成文日期（依据〔1〕第7.3.5条；〔2〕）

- [ ] 成文日期用阿拉伯数字标全年月日，年份标全称，月、日不编虚位（不写 01 月 05 日）。
- [ ] 加盖印章的公文：成文日期一般右空四字编排；印章用红色，不出现空白印章。
- [ ] 单一机关行文：发文机关署名以成文日期为准居中编排于日期之上；印章端正、居中下压署名和成文日期，署名与日期居印章中心偏下位置；印章顶端距正文（或附件说明）一行之内。
- [ ] 联合行文：各署名按发文机关顺序排列，印章一一对应下压，互不相交或相切，每排印章两端不超出版心。
- [ ] 不加盖印章的公文：正文（或附件说明）下空一行右空二字编排发文机关署名，成文日期编排于署名下一行、首字右移二字。
- [ ] 排版后空白处容不下印章、签名章或成文日期时，用调整行距、字距解决，不得将落款挤到下一页空白页。
- [ ] 附注居左空二字加圆括号，编排在成文日期下一行。

## 四、附件、版记与页码（依据〔1〕第7.3.4、7.3.7、7.4、7.5条；〔2〕）

- [ ] 有附件的，正文下空一行左空二字编排「附件：」说明；多个附件用阿拉伯数字标顺序号，附件名称后不加标点，回行与上一行附件名称首字对齐。
- [ ] 附件另面编排、在版记之前、与正文一起装订；「附件」二字及顺序号用 3 号黑体顶格编排于版心左上角第一行，附件标题居中编排于版心第三行；附件顺序号和标题与附件说明表述完全一致。
- [ ] 版记分隔线与版心等宽，首末两条用粗线（约 0.35 mm）、中间用细线（约 0.25 mm），末条分隔线与末页版心下边缘重合。
- [ ] 页码用 4 号半角宋体阿拉伯数字，编排于版心下边缘之下，数字左右各放一条一字线，一字线上距版心下边缘 7 mm；单页码居右空一字、双页码居左空一字；空白页和版记页不编页码，附件与正文连续编排页码。

## 五、拟办意见审核（依据〔7〕拟办意见写法规范；〔8〕提高拟办意见质量；〔9〕意见类文稿常见问题）

拟办前置动作（缺一项不落笔）：

- [ ] 已通读来文全文，分清来文性质：需办理答复的、需贯彻落实的、只需阅知的，三类分开拟。
- [ ] 已核对来文主送、抄送范围与领导分工、部门职责，牵头与配合关系有依据，不凭印象点名。
- [ ] 已核对来文密级、紧急程度与时限要求，急缓已在拟办中体现。
- [ ] 干部任免、召开会议、调整议事协调机构成员等有先例的事项，已对照前案办理程序、依据和结果拟办〔8〕。

拟办正文逐条核：

- [ ] 点名具体承办部门（多部门的写明牵头部门与配合部门），不写无对象的空话。
- [ ] 写明报送对象与硬时限（来文要求的上报部门、截止时间已在拟办中复述核对）。
- [ ] 「阅示」「阅处」「阅知」按事项性质细分使用，不全篇一律「请领导阅示/批示」一个模式〔7〕〔8〕。
- [ ] 只需阅知的文件只写传阅、传达范围与方式；需答复的文件写承办部门与承办时限；重大、紧急事项附办理原则建议并附背景材料供批办参考〔8〕。
- [ ] 情况不明、方案不唯一的，给出可供选择的几种方案让领导做选择题，不把问题原样上交〔8〕。
- [ ] 语气为参谋建议口吻：多用「请」字开头，不用命令口气，不带个人主观意志和感情色彩；既不写成请示、也不写成指示〔8〕。
- [ ] 已与有关单位联系洽商并形成初步意见的，在拟办中一并注明〔8〕。
- [ ] 文字简明扼要、观点鲜明，无冗长拖沓；拟办后署名、注日期〔7〕。

拟办常见错误对照（命中即改）：

- [ ] ✗ 所有来文统统「请××领导阅示」，不分办理与阅知〔7〕。
- [ ] ✗ 只点部门不给时限，或只给时限不点牵头部门。
- [ ] ✗ 承办部门与领导分工、部门职责对不上，造成「梗阻」退回重拟〔8〕。
- [ ] ✗ 依据引用说不清出自哪份文件、哪条政策，审核环节无法溯源〔9〕。
- [ ] ✗ 执行要素缺失：无责任主体、无完成时限、无报送要求，是反复退改的首因〔9〕。

## 六、向县级部门报送材料：退稿高危项（依据〔4〕《党政机关公文处理工作条例》及公开受理规范；〔5〕信息报送规范；〔10〕报送考评办法）

行文与受理类（命中任一项，上级办公室可不予受理、附退文单退回〔4〕）：

- [ ] 主送、抄送机关列明准确，不越级行文（非紧急事项），不直接报送领导个人。
- [ ] 所述事项属受文机关职责范围；涉其他部门职权的，已征求意见并达成一致（或注明未一致情况），重大事项已履行决策程序。
- [ ] 文种使用正确，格式符合《条例》与 GB/T 9704，附件齐全，所附资料与正文附件说明一致。
- [ ] 请示类公文签发人为主要负责人；一文一事，不在报告中夹带请示事项。
- [ ] 文末留有联系人及联系方式（无联系人及联系方式属不予受理情形〔4〕）。
- [ ] 电子传输报送的，报送日期与成文日期一致〔4〕。

内容质量类（退稿、退改与通报扣分高发〔4〕〔5〕〔10〕）：

- [ ] 时间、地点、单位、事件、数据等要素准确无误；数字、单位、人名、地名无明显错误，错别字与标点差错已清零。
- [ ] 文题相符、逻辑严密、条理清晰、表述规范，无歧义语句。
- [ ] 数据真实：报喜恰如其分、报忧真实可靠，不虚报、不以偏概全，喜忧兼报不截留问题信息〔5〕。
- [ ] 时效达标：有时限要求的按时报送；会议等动态信息当天报送，重大突发事件按规定时限（公开考评办法有「2 小时内上报」之例〔10〕）首报并续报进展。
- [ ] 篇幅精炼：动态类信息参考控制在 800 字以内、调研类约 3000 字，以数据和事例说话，减少会议类、过程类内容占比〔5〕。
- [ ] 审核链完整：上报材料经分管领导审核、敏感重要信息经主要负责人审定，注明起草人与审核签发人〔5〕。

## 七、汇报材料数据表述：文字与表格分工（依据〔1〕第8、9章；〔6〕会议汇报材料规范）

- [ ] 正文以文字表述为主体：关键结论、总体情况、对比结论用文字段落写清，数据嵌入叙述（「能用数字不用文字」指用具体数字代替「大幅增长」等模糊表述，不是堆表格）〔6〕。
- [ ] 数据较多、需多维度对比（如分项进度、年度对比、排名）时用表格呈现，表格比文字更直观；但正文文字量不低于图表量，图表是辅助、文字是主体，不出现「全是图表、没有文字分析」〔6〕。
- [ ] 每张表格有编号、有表题，并注明数据来源〔6〕。
- [ ] 表格编排执行 GB/T 9704 第 8 章：横排表格页码与公文其他页码保持一致，单页码表头在订口一边、双页码表头在切口一边〔1〕。
- [ ] 正文与表格中的数字用法执行 GB/T 15835、计量单位执行 GB 3100/3101/3102、标点执行 GB/T 15834（GB/T 9704 第 9 章明文引用）〔1〕；同一材料内数字口径、单位、统计时段前后一致。
- [ ] 汇报篇幅按时长换算自查：语速每分钟 200–250 字，超时先删过程、保数据与结论〔6〕。
- [ ] 与本单位现行办文口径衔接：纯公文汇报稿正文不嵌表格，数据一律文字段落表述；确需表格的，单独成表格文件随稿报送（与「图表为辅」原则一致，从严执行）。
