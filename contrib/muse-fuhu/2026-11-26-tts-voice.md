## 一、结论先行：推荐排序

针对本管线的真实需求——批量离线合成、自然口语不要播音腔、要进无人值守自动化、发布合规、成本可控——排序如下：

| 名次 | 方案 | 一句话理由 |
|---|---|---|
| 1 | **CosyVoice 开源权重 Fun-CosyVoice3-0.5B-2512（本地/免费 GPU 离线批量）** | 零样本克隆自然口语音色＋自然语言指令控情感/语速，中文与方言开源第一梯队，零接口费，Apache-2.0；与今晚学习笔记结论同向 |
| 2 | **阿里云百炼 CosyVoice API（v3.5-flash 起步）** | 与第一名同一技术线，免运维、按字付费极便宜（0.8 元/万字符起），付费云服务商用条款最干净；不想维护 GPU 时的生产替代线 |
| 3 | **火山引擎豆包语音 2.0（seed-tts-2.0 / 复刻 seed-icl-2.0）** | 中文自然度口碑高、抖音生态原生、5–10 秒可复刻；成本高于百炼（资源包约 2.4–2.8 元/万字符＋复刻 138 元/个） |
| 4 | **GPT-SoVITS v2Pro（本地）** | 1 分钟录音少样本微调、相似度高、MIT、WebUI 友好；但情感靠换参考音频、无指令控制，批量自动化要自封装，运维门槛较高 |
| 5 | **剪映 / 必剪内置配音** | 零成本、剪辑一体，适合临时出片与试听；纯 GUI 手工、无批量 API、免费音色商用口径不一，进不了无人值守管线 |
| 6 | **Edge TTS（微软）** | 免费免 key 即时可用，但情感弱、其云扬音色本身就是新闻播报风——正是要淘汰的腔调；商用条款未明确，只作临时占位与对照样片 |
| 7 | **Fish Speech S2-Pro 本地权重** | 自然度与情感标签都很强，但权重是 Research License（非商用），且要 24 GB 显存，本地路线合规不过关；其托管 API 可商用但按美元计费、国内访问稳定性存疑，仅作试听参考 |

## 三、各候选要点（附来源）

### 1. CosyVoice（阿里通义 FunAudioLLM）

- 版本谱系：开源最新是 **Fun-CosyVoice 3.0（Fun-CosyVoice3-0.5B-2512，含 RL 版，2025 年 12 月发布）**，0.5B 参数，Apache-2.0，权重在 GitHub / Hugging Face / ModelScope 三处可下；论文里的 1.5B 未开放权重；**CosyVoice 3.5 只有阿里云 API、无开源权重**。来源：https://cosyvoice.org/cosyvoice-3
- 能力：9 种语言＋18 种以上中文方言口音；零样本跨语种克隆；双向流式（延迟低至 150ms）；指令控制语言、方言、情感、语速、音量；拼音/CMU 音素纠音与数字符号自动规范化。来源同上（引官方 README 与模型卡）。
- 显存与算力：今晚学习笔记核对口径——CosyVoice 2/3（0.5B）基线约 5.2 GB 显存（权重 2.5G＋激活 2G＋缓存 0.7G），单张 T4（16 GB）绰绰有余；官方 README 未给最低显存数字（cosyvoice.org FAQ 明示），5.2G 为第三方实测口径，落地时以自测为准。来源：`~/workspace/learning/douyin-muse/2026-11-26.md` 第一节；https://cosyvoice.org/cosyvoice-3
- 本地横评定位：与 Fish Speech 同列音质第一梯队，「Fish 社区更活跃，CosyVoice 2 中文效果略优」。来源：https://www.cnblogs.com/chenying99/p/20698841
- 百炼 API 价目（中国站，元/万字符）：v3.5-flash 0.8、v3-flash 1、v3.5-plus 1.5、v3-plus 2；按输入字符计费、输出不收费；免费额度仅北京（中国站）/新加坡（国际站）地域，1 万字符、90 天。来源：https://cosyvoice.org/zh/cosyvoice-api ；https://developer.aliyun.com/article/1763252 ；声音复刻 9.9 元/个见第三方网关文档（非阿里官方页，落地前以百炼控制台为准）：https://docs.jcaigc.cn/voice/tts.html

### 2. GPT-SoVITS

- 现状：GitHub 59,000+ 星，MIT 许可；2026 年主流推荐版本为 **v2Pro / v2ProPlus**（以 v2 的硬件成本拿到接近 v4 的音质）。来源：https://pasqualepillitteri.it/zh/news/7057/gpt-sovits-shengyin-kelong-zhinan
- 用法：零样本 5 秒样本即出声；少样本用约 1 分钟干净录音微调几分钟，相似度与情感表现明显更好，正式项目应走少样本。情感靠选带对应情感的参考音频，无自然语言指令控制。WebUI 中文界面、内置人声分离/切片/降噪/ASR 转写工具链。来源同上。
- 部署：Windows 集成包双击 go-webui.bat；Linux/Mac 走 conda＋安装脚本；Docker 可选。推理显存约 6 GB+、微调建议 12 GB+（RTX 3060 级）。来源同上；横评表：https://www.cnblogs.com/chenying99/p/20698841

### 3. Fish Speech / Fish Audio

- 版本：开源线现为 **S2-Pro（4B＋0.4B 双自回归，2026-03 开源权重）** 与更新的旗舰 **Drama 3（2026-10，Community License）**；托管 API 推荐生产模型 s2.1-pro。来源：https://www.assemblyai.com/blog/how-to-generate-speech-fish-audio ；https://dev.to/tarunyadav1/fish-speech-on-mac-run-fish-audio-s2-pro-locally-1o79
- 许可（关键）：**S2-Pro 权重是 Fish Audio Research License——仅研究与非商用，商用、内部业务使用、托管 API 都须另获书面许可**；代码 2026-10-13 起为 Fish Audio Community License v1.0（年收入低于 50 万美元可免费商用，但不得对外提供托管 TTS 服务）。网上旧文写「Fish Speech 是 Apache 2.0」已过时，不得据此商用。来源：https://www.anchorterminal.com/tools/fish-audio-s2-pro ；https://ai-opensource.com/models/s2-pro/
- 硬件：官方安装口径至少 24 GB 显存（Linux/WSL＋NVIDIA，或 CPU）；权重约 11 GB。Mac 只能经第三方 Murmur 的 MLX 转换版跑 S2-Pro，许可证随权重走、商用仍须书面许可。来源同上两条。
- 托管 API 价格：s2.1-pro $15 / 1M UTF-8 字节、Drama 3 $50 / 1M 字节（按字节非字符，中文一个字占 3 字节，实际成本高于字面）。来源：https://www.assemblyai.com/blog/how-to-generate-speech-fish-audio

### 4. Edge TTS（微软）

- 本质：Edge 浏览器朗读用的同款神经网络语音服务，pip 包 `edge-tts` 免 key 调用，中文常用音色：晓晓（Xiaoxiao，温暖通用）、晓伊（Xiaoyi，明亮活泼）、云希（Yunxi，男声叙事）、云扬（Yunyang，专业克制——即新闻播报风）。参数只有 rate/pitch/volume；经验值语速降约 8% 中文断句更自然。来源：https://apishare.cc/article/fa-487682ed/en
- 口碑：音质底子是 Azure 级，但情绪起伏弱、偏平淡；多篇测评把「Edge 内置语音」自然度排在末档（★★☆☆☆）、情绪 ★☆☆☆☆。来源：https://www.cnblogs.com/newzq2/p/23559494 ；https://www.cnblogs.com/shuiyinyun/p/23600658
- 合规：接口非微软官方公开 API、无 SLA、随时可能变更鉴权；条款未明确授予商用转授权，多源明确提示免费 Edge TTS 不支持商用、商用转 Azure Speech（每月约 50 万字符免费额度、同一套音色引擎）。个别测评文写「免费商用」，口径冲突——按高风险处理，不作正式发布声线。来源：https://apishare.cc/article/fa-487682ed/en ；https://waynetalk.com/free-tts-image-api/

### 5. 火山引擎（豆包语音）

- 模型：语音合成大模型 2.0（seed-tts-2.0 公版音色、seed-icl-2.0 复刻音色）；上百音色、40+ 语种、语速 0.6–1.5 倍、流式首包 300–400ms（第三方实测）。来源：https://developer.volcengine.com/articles/7671228661858615359 ；https://docs.jcaigc.cn/voice/tts.html
- 计费：新用户免费约 2 万字符＋15 次声音训练；超自然大模型音色梯度约 6.5 元/万字符降至 4.9 元/万字符；资源包口径约 2.1–2.8 元/万字符（10 万字 28 元起）；音色年费约 150 元/年/个＋存储 1 元/月；复刻音色槽位 138 元/个、每槽位最多 10 次训练。不同来源口径略有出入，下单前以火山引擎官方计费文档为准。来源：https://developer.volcengine.com/articles/7648595943507689526 ；https://developer.volcengine.com/articles/7633281901532282907
- 定位：第三方横评给其中文自然度 9/10 并称「中文自然度领先、抖音/剪映有大量真实应用验证」——注意该文出自火山引擎开发者社区，立场非中立，作参考不作定论。来源：https://developer.volcengine.com/articles/7671228661858615359

### 6. 剪映 / 必剪等创作者工具

- 剪映：基础 AI 配音免费、导出无水印、不限基础次数；音色覆盖解说、口播、方言、童声、情绪类并持续上新；高级情绪与专属音色需会员；配音与字幕、剪辑轨道打通，长文本偶发断句生硬，无批量合成。商用：免费基础音色个人/自媒体大多允许，部分限定、明星感音色禁商用，以官方协议为准。来源：https://www.cnblogs.com/shuiyinyun/p/23600658 ；https://www.cnblogs.com/shuiyinyun/p/23679764（该文页面自带「可能是商业推广软文」提示，引用已降权）
- 必剪：B 站配套，基础配音全免费无水印，二次元与年轻向音色丰富；成熟叙事/纪录片声线偏少，商用授权范围较窄。来源同上。
- 对管线的意义：两者都是 GUI 手工工具、无 API、无批量——只能当「人工试听对照」与临时救急，不能进无人值守管线；其音色听感可作选声线的参考样本。

## 四、第一名落地实测步骤（CosyVoice 开源 Fun-CosyVoice3-0.5B-2512）

以下命令按官方 README 的 quickstart 原样引用（来源：https://cosyvoice.org/cosyvoice-3 的「Run CosyVoice3 locally」节，引 QwenAudio/CosyVoice README）。本轮只写步骤、未执行。

### 4.1 环境选择（按优先级）

1. **免费 GPU 离线批量（首选验证场）**：Kaggle Notebook（T4 x2、约 30 小时/周、单次会话 12 小时）或魔搭 ModelScope Notebook（A10 24 GB、36 小时一次性总额）——今晚学习笔记已核实额度口径，且结论明确：免费 GPU 只适合离线批量合成、不当在线后端。来源：`~/workspace/learning/douyin-muse/2026-11-26.md` 第一节。
2. **Mac 本地试听**：官方仓库以 Linux＋CUDA 为主，Mac 原生跑法未确认；Mac 上先用 ModelScope 创空间在线试听同款模型，本地部署待实测后再定。
3. **云端 VM**：本机云 VM 无 GPU 时 CPU 推理速度未确认，不作首选；要常驻 API 再评估百炼（第 2 名）或 vLLM 部署。

### 4.2 安装（Linux / Kaggle / 魔搭 Notebook 内）

```bash
git clone --recursive https://github.com/QwenAudio/CosyVoice.git && cd CosyVoice
conda create -n cosyvoice -y python=3.10 && conda activate cosyvoice
pip install -r requirements.txt
python -c "from huggingface_hub import snapshot_download; snapshot_download('FunAudioLLM/Fun-CosyVoice3-0.5B-2512', local_dir='pretrained_models/Fun-CosyVoice3-0.5B')"
python example.py
```

备注：仓库已从 FunAudioLLM/CosyVoice 迁至 QwenAudio/CosyVoice（旧址自动跳转）；国内网络下模型改走 ModelScope 同名仓库 `Fun-CosyVoice3-0.5B-2512` 下载（来源：https://cosyvoice.org/cosyvoice-3 的模型分发表）。example.py 跑通官方示例即算环境关通过。

### 4.3 零样本克隆试听（核心验证）

1. 备参考音：用**本人声音或已获明确授权的声音**录一段 5–10 秒自然口语（日常说话语气，不要朗读腔），WAV 格式；逐字写下这段话的原文（prompt_text 必须与录音逐字一致，口径来源：https://studio.aifilms.ai/blog/fun-cosyvoice-3-open-source-multilingual-voice-cloning ）。
2. 用零样本模式合成测试稿（调用 `inference_zero_shot`，参数以仓库 example.py 为准）；同一参考音再用指令模式（`inference_instruct2` 一类接口，名称以仓库现行代码为准）各出一版带指令的：「用轻松聊天的语气，语速稍慢」等指令验证情感/语速控制是否生效。
3. 测试稿固定一份、四类句子齐全（沿用测评业通行做法）：①含数字与单位的句子（「2026 年增长 3.5%」类）；②多音字/儿化音句子；③中英混读句（AI、GPU 等词）；④长句（60 字以上）验断句。来源：https://www.cnblogs.com/newzq2/p/23559494 的翻车点清单。

### 4.4 测试方法与过关标准

- **三方同稿盲听**：现新闻腔成片同段文案、CosyVoice 零样本版、百炼 v3.5-flash 版（免费额度内）各一段，打乱顺序听，只记感受不看标签。
- **逐项计数**：断句错误数、多音字读错数、数字读错数、明显电音/吞字处——四项逐段数，写进验收记录，不许只写「感觉不错」。
- **性能记录**：合成耗时与实时率（RTF）、峰值显存——决定批量排期时用哪台机器。
- **最终门**：样片必须经用户亲耳听过点头才准批量生产（23:06 整改口径）；未点头前只出样片、不动存量排期。
- **合规门**：参考音来源留档（谁的声音、何时授权）；发布时按现行管线口径标注「含 AI 生成内容」。

## 五、风险项

1. **CosyVoice 许可证张力**：权重与代码标 Apache-2.0，但官方 README 同时写明内容仅供学术与演示（cosyvoice.org FAQ 原话是提醒读者同时读两者并咨询法律意见）。自媒体发布属公开传播，正式批量前须把 README 原文再核一遍；若口径不清，退路是走百炼付费 API（第 2 名）取得干净的服务条款。来源：https://cosyvoice.org/cosyvoice-3
2. **声音人格权**：克隆只许用本人或有明确授权的声音；用未授权真人声音（主播、明星、他人）做克隆发布方案，一律禁区，本方案不提供此类路径。测评文亦提示参考音频复刻用于商业内容有声音人格权侵权风险，并须按《互联网信息服务深度合成管理规定》依法使用、必要时标注。来源：https://www.cnblogs.com/shuiyinyun/p/23615711
3. **Fish Speech 许可误读**：旧文称其 Apache 2.0 已过时；S2-Pro 权重实为非商用 Research License，照旧文部署发布会踩许可。来源：https://www.anchorterminal.com/tools/fish-audio-s2-pro
4. **Edge TTS 接口风险**：非官方公开接口、无 SLA、鉴权随时可变，管线押在它上面随时断供；且商用授权未明确。只作临时用途。来源：https://apishare.cc/article/fa-487682ed/en
5. **免费 GPU 不是生产后端**：Kaggle 每周约 30 小时、闲置 20 分钟断会话、模型每次重下；魔搭 36 小时是一次性总额。只做离线批量合成，排期须留额度余量。来源：`~/workspace/learning/douyin-muse/2026-11-26.md` 第一节。
6. **云 API 价格易变**：百炼、火山价格均为 2026 年 10–11 月所见口径，下单/充值前以各控制台实时报价为准；火山不同来源单价口径出入较大（1.3 元/千字与 2.1–2.8 元/万字符并存），须以官方计费文档复核后再预算。来源：https://cosyvoice.org/zh/cosyvoice-api ；https://developer.volcengine.com/articles/7648595943507689526
7. **剪映/必剪商用口径不一**：免费音色「可商用/仅限个人」两种说法并存，未确认到官方统一口径；账号已变现的情况下不要拿剪映免费音色当正式声线。来源：https://www.cnblogs.com/shuiyinyun/p/23679764
8. **方言与口音**：本管线内容以普通话口语为主；若日后要柳州/广西地方口音，CosyVoice 3 的 18+ 方言是加分项，但具体到广西口音的相似度未确认，须实测。
