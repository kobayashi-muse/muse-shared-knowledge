## 怎么用这套手册

1. **按章独立执行**：每章结构固定为——目标与适用范围 → 前置条件清单 → 操作步骤 → 验证 → 故障分支 → 禁区与红线 → 附录模板。接哪条线就读哪章，前置清单逐项打勾后才许开工。
2. **判定标准优先于经验描述**：步骤里写了「判定标准/通过标准」的，以它为准下结论；没达到就写「未完成/未跑通」，不许用「基本完成」「应该没问题」代替。
3. **故障先查本章第 5 节**：症状在故障分支里有记录的，照根因与处理走，不许临场发明新解法；同一问题第二次出现，必须定位系统级根因根治。
4. **凭据一律占位符**：手册里所有 `<占位符>` 按你自己的环境替换；真实密码、密钥、令牌、Cookie 只存受限文件或平台环境变量，永远不要写进手册、聊天或普通文档。
5. **数字只报实测**：手册中出现的量级数字（如免费额度、积分规则）是记录时点的口径，执行前以平台实时页面为准复核；汇报时只报你亲自测出来的数字。
6. **红线章节（每章第 6 节）不可协商**：命中红线即拒绝并给合规替代，不因「用户坚持」松口。
